NETWORK TOOLKIT 1.17.35

Application source uses Go's standard library, operating system APIs, and the
included official Go x/crypto and x/sys modules. SSH is compiled into the EXE.
The browser interface includes the locally bundled xterm terminal renderer and
Fit/Search/Serialize addons under the MIT license.
The compiled-in loader adapts ISC-licensed source from OpenWebView2Loader
and Wails go-webview2; attribution and license follow below.
The installed Microsoft WebView2 Runtime is a system prerequisite. No additional
language runtime, online font, CDN asset, external SSH or Telnet program, serial
package, or companion WebView2 loader DLL is required for built-in tools. The
third-party application dependencies listed here are included at build time.

The supplied Windows executable includes Go runtime and standard library code.
Their license follows.

GO-NATIVE WEBVIEW2 LOADER

The loader adaptation is included as source and compiled into the EXE.
It derives from Wails go-webview2 v1.0.23, commit
e08e9397f04ad0b1050d7e5bdc8e27faddc87987, and OpenWebView2Loader.
The optional upstream native DLL loader and in-memory loader are not included.
No third-party Go module dependency is required to build this adaptation.
The Microsoft WebView2 Runtime remains a separate installed Microsoft component.

IEEE REGISTRATION AUTHORITY DATA

Network Toolkit embeds selected factual fields from the IEEE public MAC
assignment registries: MA-L, MA-M, MA-S, and legacy IAB. The table contains
registered prefixes, organization names, and registry names. Source data
belongs to its respective rights holders. Attribution does not imply IEEE
endorsement or identification of a device's model.

The source registry index is:
https://standards.ieee.org/products-programs/regauth/

CSV sources:
https://standards-oui.ieee.org/oui/oui.csv
https://standards-oui.ieee.org/oui28/mam.csv
https://standards-oui.ieee.org/oui36/oui36.csv
https://standards-oui.ieee.org/iab/iab.csv

The bundled snapshot was retrieved on 2026-10-20 and contains 58,808 unique
prefixes. Original download hashes, sizes and Last-Modified values are in
source/internal/identity/data/SOURCE.txt. Rare historical prefixes with more
than one listed organization retain all organization names. No mailing
addresses or additional IEEE documents are included in the embedded table.

XTERM TERMINAL RENDERER AND ADDONS

@xterm/xterm 6.0.0
@xterm/addon-fit 0.11.0
@xterm/addon-search 0.16.0
@xterm/addon-serialize 0.14.0
https://github.com/xtermjs/xterm.js
https://xtermjs.org/

The xterm.js bundle includes one local decoration-index correction. Queued
deletions find entries by object identity rather than a marker's mutable row
key, and duplicate queued deletions are rejected. Lazy cleanup is preserved.
The exact change is reproducible with scripts/patch_xterm_decoration_index.py;
ordinary source builds use the included patched asset and still need Go only.
Other browser UMD bundles and the stylesheet are unmodified.
No runtime network request loads these dependencies. Exact npm tarball URLs,
SHA-512 package integrity values, and original/patched SHA-256 file hashes are in
source/web/assets/SOURCE.json. The full MIT licenses follow.
