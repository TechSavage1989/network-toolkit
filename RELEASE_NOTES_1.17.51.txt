NETWORK TOOLKIT 1.17.51 - RESPONSIVE SERVER LAYOUT AND SHARED SESSIONS

New in 1.17.51

1. SFTP/TFTP/FTP SERVER LAYOUT
- Network adapter selector is on the left, with a compact Listening Port
  field immediately to its right on the same row. The adapter no longer
  consumes the full server settings width. Labels, full adapter names and
  hints remain within the correct elements at desktop and narrow widths.
- Long adapter descriptions wrap in the selector. No separate duplicate label.

2. UNIFIED SAVED AND RECENT CONNECTIONS
- SFTP Client and FTP/FTPS Client now have prominent Saved and Recent controls
  with searchable terminal-style session rows, action controls, double-click
  to connect, and contextual actions for edit, rename, duplicate, save and
  removal. The existing source selectors are retained for quick access.
- Saved SSH terminal profiles and SSH terminal recent connections appear
  in SFTP. FTP/FTPS saved and recent connections are also available from
  the Terminal's Saved and Recent sidebar, with routing into FTP/FTPS Client.
- FTP/FTPS connections automatically enter Recent after a successful login.
  Profiles and history save server and authentication method, not passwords.
  Stored credentials continue to use the protected credential vault.
- SFTP history is shared with Terminal's recent SSH connection list.

3. SAVED SSH PROFILE RELIABILITY
- When a saved SSH profile matches an authenticated active SSH terminal,
  the SFTP client reuses that existing terminal connection and its verified
  SSH host key without requesting separate login details.
- If no matching active terminal exists, saved SSH credentials and trusted
  terminal host-key records are reused for an independent SFTP connection.
  A stale SFTP-specific fingerprint cannot override Terminal's trusted key.
- Unknown or changed SSH host keys still require independent verification.
  No mismatched SSH fingerprint is automatically trusted or replaced.

4. FILE BROWSER HOME AND ROOT CONTROLS
- Home and Root navigation actions are available in both panes of the main
  SFTP/FTP/FTPS file browser and in the dynamic SSH terminal SFTP sidebar.
  Home follows the initial server folder; Root navigates to the filesystem
  root or local drive root. Back, Forward, Parent, and Refresh remain.

VALIDATION
- Complete Go tests and JavaScript regression tests pass.
- Browser rendering smoke checks cover Saved/Recent in SSH, FTP/FTPS and
  adapter + listening-port geometry at five window widths.
- The executable is compiled for Windows x64 with the icon and version
  embedded during compilation, not patched into the compiled binary.
- Physical Windows GUI testing and live SSH/FTP network testing were not
  available in this build environment. Test against your target devices
  before deploying to production.
