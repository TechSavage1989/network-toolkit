Network Toolkit 1.17.104

Saved credential security
- Set up a master password in a native Windows dialog. The versioned vault encrypts passwords, private keys, usernames, names and destination metadata using authenticated encryption; Argon2id protects its password-wrapped random key. Master passwords are never saved or sent to the web interface.
- Remembered unlock is selected by default, as requested: a Windows CurrentUser DPAPI-protected unlock key reopens the vault after app restarts and Windows reboots. Software running as the same Windows user can still access remembered unlock. This is convenience, not protection against same-user malware, administrators or a compromised operating system.
- Optional offline recovery is offered during setup or password change and requires native acknowledgment and re-entry. Keep it separately: it unlocks the vault. There is no vendor recovery or silent unprotected fallback.
- Existing DPAPI vaults require explicit setup/migration; the verified new vault is activated without silently deleting the retained legacy copy. Remove that older, weaker-protected copy only through its separate native confirmation after checking recovery/backups. Configuration reset forgets automatic unlock but keeps encrypted vault files. Deleting one connection never deletes the entire vault.
- Lock and forget clears current key access, stops remembered unlock and blocks new saved-credential connections/reconnects; established authenticated sessions remain connected. There are no automatic idle/workstation-lock prompts in remembered mode. Password change and recovery rotate vault identity/key and invalidate old remembered records.
- Saved secret retrieval is removed. Connection requests use backend credential IDs with explicit destination binding and native approval; SSH host identity and FTPS certificate/pin checks remain mandatory. Saved credentials cannot be used with Telnet or plaintext FTP. Reconnect no longer caches plaintext authentication.
- Native WebView bootstrap no longer exposes the full application capability in unauthenticated HTTP HTML. Only initial trusted native document navigation is allowed; reload/new frames fail closed. WebView2 API minimum is 122.0.2365.46; use the latest patched Microsoft Evergreen x64 runtime. Unsupported runtime errors link to the official installer; nothing installs automatically.
- Non-Windows credential storage fails closed. New encrypted files use private Windows ACLs. Same-user malware, privileged attackers, remote output/transcript secrets, memory copies and retained backups remain explicit limits; this is not an independent security audit or certification.

Terminal paging and defaults
- Recognizes the full switch prompt "-- MORE --, next page: Space, next line: Enter, quit: q" and supported pager variants, including split chunks and terminal controls, without automatically accepting unrelated confirmation prompts.
- Auto/manual paging remains part of the originating command or paste, so last-command/last-paste output covers the full paged result. Repeated page prompts are handled by distinct episodes, not a fixed delay.
- New or unset preferences default to Auto pager on and Ctrl+C copying a selection, otherwise sending Ctrl+C. Existing explicit choices are preserved.

Graphs and icon
- Condensed All-mode newest-point spacing matches the local slope of Linear 30 seconds, progressively compressing older history into the existing single left cluster. Default recent detail 60 seconds corresponds to about 64.921 seconds of visible history; explicit ranges/timeframes, irregular timestamps and retention limits stay truthful.
- Integrates the supplied Network Toolkit SVG as the canonical editable source and safe derived runtime SVG/PNG/ICO/Windows resources, without redesigning it.

Build maintenance
- Uses supported patched Go 1.26.10 and checksum-verified canonical vendored dependencies. Required checks include Linux/Windows known-vulnerability scans; unused/unvendored OpenPGP module advisory GO-2026-5932 has no fixed version and is not hidden by a blanket 'vulnerability-free' claim.
