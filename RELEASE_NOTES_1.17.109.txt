NETWORK TOOLKIT 1.17.109

MORE ROOM FOR ACTIVE TOOLS AND DOCUMENTS

- Remove the redundant global top bar. Computer identity and accessible theme,
  settings and running-work controls remain available without another full toolbar.
- Keep navigation accessible in expanded, collapsed and compact layouts while
  allowing the active tool to use the reclaimed vertical space.
- Replace the editor's permanent Move documents row with compact, explicit access
  to its existing acknowledged move/merge controls.
- Collapse the Local file and Connected session forms independently and remember
  their presentation state in the main window. Detached choices last for that
  window lifetime. Reclaimed space goes to editing and comparison.
- Preserve unsaved documents, Undo, selection/scroll, safe file writes and native
  window ownership; existing108 activity, bookmarks, graphs, vendor syntax and
  security behavior remain unchanged.

Layout evidence uses synthetic documents and actual hosted normal/narrow renders,
with direct height comparisons against the published108 UI. No private reference
screenshots or configuration contents are included in public source or packages.
