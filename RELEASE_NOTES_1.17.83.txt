Network Toolkit 1.17.83

What's new
- Manage macro folders like saved sessions, including Unfiled and Move to folder.
- Run local Command Prompt and Windows PowerShell inside the themed terminal.
- Automatically fit scan columns with compact spacing and reserved copy controls.
- Show open TCP ports as compact service-labelled badges.
- Overlap independent discovery checks and publish reachability before details.
- Bound slow Windows hostname lookups while retaining operating-system DNS policy.
- Show measured download progress and separate verification/staging phases.
- Keep a native installation activity window visible until the updated UI starts.

Local shells require Windows 10 version 1809 or Windows Server 2019 or later.
Installation time is not predictable, so its bar indicates activity, not a
percentage. The first update from an older build uses that older installer.
