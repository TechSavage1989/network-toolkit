Network Toolkit 1.17.133

## What's New

- Disconnect or reconnect multiple terminal sessions more easily with side-by-side controls and separate dropdown arrows.
- Choose whether Reconnect all, Disconnect all or Close all tabs asks for confirmation.
- Change your mind at any time using the confirmation options in Terminal display settings.

## Additional Details

- The active Terminal commands place Disconnect directly beside Reconnect. Both keep their original single-session buttons and gain separate arrow menus for Disconnect all and Reconnect all.
- Bulk actions apply only to eligible terminal sessions owned by the current window. Detached or unowned sessions and sessions being transferred are excluded.
- Reconnect all, Disconnect all and Close all tabs each have an independent confirmation preference, initially enabled. Each confirmation dialog includes a Do not ask again checkbox.
- The three bulk preferences are stored with existing application settings and included in detached-workspace display preferences. They can each be turned back on in Display settings without changing the existing individual-tab close confirmation.
- With a confirmation disabled, the chosen bulk action runs immediately, but session identity, ownership, state and eligibility are still checked before each operation. Duplicate bulk operations are blocked while one is running.
- Disconnect all ends eligible live sessions but preserves tabs and retained output. Close all tabs removes eligible tabs. Reconnect all may interrupt active work or queued input and pauses when interactive sign-in is required.
- Existing saved profiles, credentials, Terminal tools, portable updater, settings folder and stable Network_Toolkit.exe name are unchanged. Test coverage uses synthetic sessions; real devices may require further compatibility checks.
