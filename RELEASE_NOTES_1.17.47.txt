NETWORK TOOLKIT 1.17.47 PORTABLE
24 October 2026

THEMES AND CUSTOM COLORS
- Imported the complete supplied MobaXterm Current_global_color_theme.mxtcolors
  16-color ANSI palette as a selectable terminal theme.
- Added pastel and additional terminal presets, with selectable ANSI foreground,
  background and accent colors and editable hexadecimal color entries.
- Expanded app accent and diagnostic color palettes with consistent swatches
  and editable HEX inputs.
- Added editor color presets (dark, light, pastel, forest, high contrast,
  follow app, and custom) and editable syntax color values.

FILE TRANSFER AND CONNECTION PROFILES
- Moved FTP/FTPS beneath the SFTP file-transfer tool; choose protocol using
  the file-transfer client interface. Removed duplicate FTP main navigation.
- Added FTP/FTPS profile create/save/load/rename/delete using the existing
  local settings workflow. Connection profiles may reference credentials in
  the existing protected credential vault; passwords are not stored in plain
  profile settings.
- SFTP continues to support saved SSH connection profiles and existing
  authenticated SSH terminal sessions.
- Added experimental native single-file drag-out to Windows Explorer from
  local and remote panes in the main file manager and from the terminal
  SFTP sidebar, using a short-lived single-use transfer ticket that contains
  no SSH passwords, private keys or session details in the drag URL.
- Retained Windows drag-in uploads, in-app local/remote drag-drop, file and
  folder management, and terminal-linked SFTP access.

LOCAL TOOLS TEXT EDITOR
- The standalone Text Editor is a Local Tools tab. It is also used for
  editing text files from SFTP, FTP/FTPS and the terminal SFTP browser.
- Local Windows editing supports direct file paths, a file picker when the
  host supports writable file handles, and drag/drop from Explorer.
- Added document tabs and a configurable editing interface: syntax language,
  line numbers, highlighting, regex find/replace, indentation, word wrap,
  line-ending selection, go-to-line, comment/duplicate/trim/sort operations,
  case conversion, JSON formatting, and custom syntax colors.
- Supports UTF-8 and BOM-identified UTF-16 LE/BE text with encoding-preserving
  saves; limited to 8 MiB of text per document.
- Save safeguards detect stale file revisions; remote servers do not support
  atomic cross-client compare-and-save, so concurrent edits during the final
  upload remain possible. Nothing autosaves.

BUILD AND VALIDATION
- Built a self-contained Windows x64 Go executable with bundled web assets.
- Go unit/integration tests and JavaScript regression tests passed.
- Chromium source-UI smoke-tested SFTP, FTP/FTPS and editor screens.
- The native Windows executable, physical network devices, and actual
  Explorer OS-level drag-out were not tested on Windows in this environment.

LIMITATIONS
- Explorer drag-out supports one regular file at a time, not directories or
  multi-selection. Fall back to Download or the in-app local browser as needed.
- Local desktop editing requires a writable file handle or an absolute local
  path supported by the current host; imported files without one require Save
  As or Save copy. Binary or unsupported document formats are not interpreted
  as editable text, and rich-text/office documents are not parsed.
- Prefer SFTP or FTPS: plain FTP transmits credentials and data unencrypted.
