Network Toolkit 1.17.141 Beta 5

## What's New

- Editor connection settings keep the active Files and Connections controls in place when they are already open.
- Dragging the Editor comparison map uses more precise scroll positions.
- TFTP and SFTP file browser dividers can be resized with keyboard controls or reset with a double-click.

## Additional Details

- This is an opt-in interface-polish prerelease; the normal stable update channel remains v1.17.136.
- Choosing the already-open Editor sidebar panel no longer needlessly remounts the connection toolbar. Connection settings focus the currently visible control and do not replace a later user focus.
- The comparison map retains fractional aligned-scroll coordinates when dragging rather than always rounding to source-line boundaries. Document content, undo/redo state, and source ownership remain unchanged.
- The TFTP/SFTP server file explorer divider supports Arrow Left/Right, larger Shift steps, Home/End limits, and double-click reset. Live drag work is coalesced, uses current pane dimensions, commits the final pointer position, and restores the previous split if cancelled or window focus is lost.
- Existing SSH/Telnet/serial transports, FTP/SFTP credentials, network diagnostics, scan permissions, packet capture, saved settings, stable executable name, and updater confirmation requirements are unchanged.
- Historical Editor alignment and narrow-window CI issues are tracked separately; this release does not claim universal comparison-motion correction without browser acceptance. Physical Windows and device testing remain necessary.
