Network Toolkit 1.17.43 Portable

Changes:
- Fixed TFTP and unencrypted FTP start confirmation buttons: valid action and protocol attributes are now interpolated, allowing Start server to execute after confirmation.
- Shows complete selected adapter names and IPv4 addresses in a readable wrapping field below the selector for SFTP, TFTP and FTP server settings. Native dropdown selection remains available.
- Added inset spacing and responsive wrapping to server settings headers, values, buttons and confirmation dialogs.
- Prominently displays resolved IP address in Ping, Traceroute and DNS result panels when returned by the diagnostic.

Not yet implemented:
- Reusing a live SSH terminal connection for the SSH file browser. The two currently use different back-end connection lifecycles. Session sharing needs coordinated authentication, host-key verification and teardown handling, not just copying connection fields.

Validation:
- Native Go test suite passed.
- Embedded inline JavaScript and transfer-server.js passed node --check.
- Windows x64 GUI cross-compile passed.
- GUI behavior was not manually tested on Windows.
