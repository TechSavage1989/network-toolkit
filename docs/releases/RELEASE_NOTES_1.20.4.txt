Network Toolkit 1.20.4 Beta 2

## What's New

- Typing in the Terminal responds faster. Work that ran after every keystroke and every piece of output has been trimmed, so echoed characters appear sooner and the console feels less sluggish, especially when the screen is full of highlighted text.

## Additional Details

- Each keystroke is sent to the device right away instead of after a short delay, and keystrokes that arrive while a request is in flight travel together in one request.
- Output highlighting now re-checks only the rows whose text changed and remembers what it already analyzed, instead of re-analyzing the whole screen after each write.
- The Terminal tools panel's appearance editor is no longer refreshed while it is hidden, and two page-wide change watchers now ignore the terminal's own rendering, which had been forcing layout work on every keystroke.
- Nothing about what is sent, shown or saved changes. Saved targets, connection profiles, credential vault, macros, unsaved documents, sessions and settings are kept. Security confirmations and Windows/UAC approval are unchanged.
- This is an opt-in beta. Stable users stay on 1.20.2. Portable executable filename remains Network_Toolkit.exe.
- Validation uses hosted and synthetic fixtures; the owner's feel on real hardware is the acceptance check.
