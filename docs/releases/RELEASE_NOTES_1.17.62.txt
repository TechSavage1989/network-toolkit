NETWORK TOOLKIT 1.17.62

Stable Network_Toolkit.exe name for official installations. Existing custom names
stay unchanged. One-time migration retargets exact matching per-user Desktop and
Start Menu shortcuts while preserving their fields and backing them up under the
settings folder. Pinned/shared/other-location shortcuts may need manual updating.
No new persistent pointer, helper, log or backup files beside the executable.
Legacy app-owned pointers are removed after healthy canonical relaunch and safe
shortcut/alias cleanup. Update state and one prior backup live under settings.
Transient same-volume swap files remain necessary for atomic Windows replacement;
failed or locked recovery files are preserved with a warning rather than deleted.

Automatic checks are initialized independently of unrelated system/job loading,
with saved preferences loaded first, bounded early transient-error retries and
visible background-check status. No automatic download or installation.

Native Windows runtime behavior has not been exercised in this cloud build.
