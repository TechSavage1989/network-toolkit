Network Toolkit 1.17.66

What's new
- Checks for new releases every five minutes while the app is visible and online.
- Checks when you return to the app if the last check is at least two minutes old.
- Removes repeated release notes and simplifies the install confirmation.
- Preserves saved settings, automatic-check opt-out and 24-hour reminders.

This uses periodic checks, not push notifications. Network failures and GitHub
service limits can delay detection. Hidden or offline windows pause checks.
Downloads still require your action, and installation requires a separate
Install and restart confirmation. Active-work protections remain unchanged.
