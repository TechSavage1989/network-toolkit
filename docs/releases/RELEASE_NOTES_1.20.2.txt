Network Toolkit 1.20.2

## What's New

- The progress bar shown while an update downloads, installs and restarts moves again. A shared style from the redesign had stopped it animating.

## Additional Details

- This stable release includes the 1.20.1 beta. Its version is higher than every beta, so beta users receive it too.
- The rounded corners of progress bars now come from the bar and fill rather than the element itself, which is what lets the browser engine animate an indeterminate bar. A browser check verifies the animation on every build.
- Saved targets, connection profiles, credential vault, macros, unsaved documents, sessions and settings are kept. Security confirmations and Windows/UAC approval are unchanged.
- Portable executable filename remains Network_Toolkit.exe.
- Validation uses hosted builds and synthetic fixtures; the owner confirmed the animation on Windows with the 1.20.1 beta.
