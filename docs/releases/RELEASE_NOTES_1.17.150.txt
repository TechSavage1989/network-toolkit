Network Toolkit 1.17.150 Beta 14

## What's New

- File browsing through an existing SSH terminal is more reliable after quick responses.
- Reduces the chance of an SFTP timeout interfering with an operation that has already finished.

## Additional Details

- A shared-connection SFTP response timeout now disarms its pending callback before the completed exchange returns, preventing a late timer from closing the scoped SFTP channel.
- Added a repeated successful-response regression that verifies the timeout does not close the finished SFTP operation.
- Existing terminal authentication, host-key verification, network permissions, file operations, cancellation, saved settings and transfer confirmation are unchanged.
- This beta does not resolve the existing 390px Editor comparison motion regression, which still exceeds the original 2 CSS pixel threshold in the previous release's hosted browser test.
- Physical Windows multi-hour testing and real-device SFTP interruption acceptance remain pending. The beta is not certified as stable.
- This is an opt-in beta; update installation still requires approval and the executable remains Network_Toolkit.exe.
