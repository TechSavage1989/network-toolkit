Network Toolkit 1.17.108

Live activity and saved connections
- Compact sidebar activity indicators reflect actual connected sessions, listening servers and running operations. Saved profiles, open tabs and old results do not imply live activity. Status inspection does not initiate connections, scans or privileged helpers.
- Saved-connection bookmarks move into existing result addresses and matching TCP-port controls instead of a far-right control. Selected-device details expose the same profile review and chooser without bypassing authentication or connecting automatically.
- Profile updates, keyboard access, copying and narrow/light/dark layouts remain supported. FTP/FTPS clients open transports per operation, so their activity describes a running operation rather than an idle configuration.

Graph interaction
- Individual result points use result-status colors; connecting lines follow the selected theme accent.
- Stable highlight updates avoid unnecessary marker replacement. Vertical alignment within the plot can highlight/select a point, preserving the pressed sample identity while new results arrive and retaining pan/zoom/cluster behavior.

Text editor
- Typing or pasting before opening a document now creates an in-memory Untitled tab immediately. Unsaved work survives tool navigation, and theme/wrap controls operate on that document without rewriting line endings.
- Accessible multi-document tabs retain independent document state and editing protections. Editor windows and documents can be moved through explicit ownership-transfer controls without competing editable copies. Cancelled or failed moves/close requests retain the original document. Desktop browser file handles and per-request FTP/FTPS bindings cannot be safely transferred and remain in their original window.
- Conservative network-configuration recognition adds supported vendor text formats alongside existing code languages, with Auto/manual/plain-text controls and synthetic-only validation. Supported lexical families include Aruba CX/AOS-S/Comware, FortiOS, SonicOS CLI text, PAN-OS set/XML and Cisco IOS/XE/NX-OS/ASA; ambiguous or opaque exports are not guessed or decoded.
- Local side-by-side document comparison identifies additions, removals and changed lines, with previous/next navigation and synchronized scrolling.
- A full-document change map shows changes and the viewport; click or drag anywhere to navigate. Fit/zoom and scrolling of the overview are separate from editor font zoom.

Safety and verification
- Existing vault/host-key protections, terminal paging/output archives, file-transfer safeguards and updater behavior remain intact. No documents are uploaded externally for comparison.
- Tests use synthetic data/files and safe test sessions, not production devices or Windows security-setting changes. Detailed state sources, bounds, evidence and limitations are recorded in the release handoff.
