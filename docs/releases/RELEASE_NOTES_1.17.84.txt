Network Toolkit 1.17.84

What's new
- Remove Fit console from terminal controls and context choices. Terminal sizing
  continues automatically when the pane, window or font changes.
- Recognize 300 language choices using file extensions, common filenames and
  script headers, with a per-document manual override.
- Bundle dedicated offline syntax grammars for PowerShell, Batch, C/C++/C#,
  Java, JSON/JSONC/JSON Lines, HTML/XML, Markdown and many more languages.
- Format JavaScript/TypeScript, JSON/JSONC/JSON5, HTML/Vue, CSS/SCSS/Less,
  Markdown, YAML and GraphQL using local parsers. Format is an explicit action.
- Indent PowerShell and C-family code while preserving multiline strings,
  comments and preprocessor macros. This action adjusts indentation only.
- Add language-aware Enter indentation, selection Tab/Shift+Tab and correct
  line/block comment toggles. Highlighting and opening do not rewrite files.
- Display local PowerShell and Command Prompt prompt syntax using the selected
  terminal ANSI palette. Explicit shell colors retain precedence; transcripts,
  selection, keyboard input and full-screen applications remain intact.

Language tools run locally in bounded workers. Large files retain the plain-text
editing path. No source is executed or sent to an external language service.
