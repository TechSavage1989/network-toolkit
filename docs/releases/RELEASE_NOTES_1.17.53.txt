NETWORK TOOLKIT 1.17.53
Released: October 24, 2026

SERVER ACTIVITY
- SFTP, TFTP and FTP/FTPS server activity has a larger dedicated panel.
- Drag the horizontal divider above Live server activity to resize it.
  Drag upward for more activity space and downward for more file space.
- The focused divider also accepts Up/Down arrow keys. Hold Shift for
  larger steps. Double-click or press Home to restore automatic sizing.
- Each protocol retains its preferred activity height and settings sidebar
  width. Resizing a window temporarily constrains the activity height
  without discarding the saved preference.
- Removed the nested log height limits that prevented larger panels from
  displaying additional records. The activity area scrolls as one region.
- Compact file-browser controls retain file-list room in smaller panels.
- Server file action buttons wrap instead of overlapping their text.

SERVER ADAPTER SELECTOR
- Adapter options retain their full wrapped height, including long adapter
  descriptions and IPv4 addresses. Options no longer compress and overlap.
- The expanded adapter list uses the available settings-sidebar width.
- Fixed clipping inherited from generic collapsible-panel styles.
- The selected adapter remains on the left of the listening port.
- Selection updates the server configuration and listening address.
- Arrow keys, Home/End and Enter/Space can select an adapter. Escape,
  clicking outside, or moving focus away closes the list.
- Adapter changes remain disabled while the server is running.

SAVED SSH / SFTP CONNECTIONS
- The working SSH connection policy and saved-profile connectivity from
  1.17.52 are retained. This release changes server interface layout and
  layout-preference persistence.

PACKAGE
- Windows x64 GUI executable with compile-time embedded icon and version.
- Complete editable Go and web source, vendored dependencies, and build
  scripts. The executable does not need the source folder to run.
- See VALIDATION.txt for the checks performed and environment limitations.
