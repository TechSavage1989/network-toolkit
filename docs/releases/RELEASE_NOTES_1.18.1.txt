Network Toolkit 1.18.1 Beta 1

## What's New

- Shared controls now look and behave more consistently throughout Network Toolkit.
- Improved focus indicators and spacing make common actions easier to follow.
- Windows have practical minimum sizes so controls are less likely to overlap.
- Automatic update checks run at startup and then every six hours, while manual checking remains available.

## Additional Details

- Introduced shared visual roles for spacing, type sizes, surfaces, borders, focus rings, radii and elevation, used across buttons, inputs, tabs, panels, progress bars, notices and empty states.
- Native main window minimum: 960 by 600 logical pixels. Detached Terminal and Editor minimum: 640 by 400 logical pixels. Previously saved bounds are fitted to the available screen without resetting the saved settings.
- Background update checks use a six-hour successful-check interval. Error retries retain rate-limit and network backoff behavior; manual checks are unchanged.
- Credentials, credential vault, saved targets/profiles, macros, unsaved Editor work, Terminal sessions, network permissions, Hosts/IP/adapter review, explicit download/install consent and checksums are not intentionally changed.
- The historical 390px comparison-motion pixel tolerance is retired by the owner, since unsupported widths are outside the new minimum. Other behavioral and document-integrity checks remain enabled.
- Screenshots are captured with synthetic fixtures in hosted CI. Native physical Windows and real-device acceptance are not claimed.
- The release remains opt-in. Existing stable latest stays on v1.17.136 until a future stable release.
