Network Toolkit 1.21.15 Beta 16

## What's New

- Rule set colors are now named by what they mark, such as Errors and failures, since you can change the colors. Name the colors of your own and imported sets.
- Every rule set has the Device prompts card from Universal: color the device prompt, pick its color and choose how the device's name is shown.

## Additional Details

- Built-in rule sets use their own descriptions (for example "Up, permitted, names and descriptions"), list only the colors they use, and show which MobaXterm color each one is in .msyn files.
- Your own and imported sets list all seven colors with an editable name; until you name one, it shows the usual MobaXterm meaning (Errors and failures, Success, Warnings, Other keywords, Addresses and values, Information, Web addresses). Duplicate copies the names. Names are saved with the rule set and are not written to exported .msyn files.
- Legend chips and color picker titles use the same names.
- Device prompts with keyword rule sets: the prompt (such as switch# or user@host:~$) is colored with the Device prompt color where the device doesn't color it, like Universal. Rule set words inside the prompt give way to it. Switch it off per rule set in that set's Device prompts card; the color and the device name choice are shared by every profile.
- Change from 1.21.14: keyword rule sets now color device prompts by default. Turn it off in the rule set's Device prompts card if you prefer the old look.
- Settings, saved values and their effects are unchanged apart from the additions above.
- Validation used unit tests and browser checks with sample text; no real device was used, and it has not yet been checked on a physical Windows PC.
- Saved targets, connection profiles, credential vault, macros, unsaved documents, sessions and settings are kept. Security confirmations and Windows/UAC approval are unchanged.
- This is an opt-in beta. Stable users stay on 1.20.16. Portable executable filename remains Network_Toolkit.exe.
