# Settings and Updates

Open Settings from the main window to search nine sections: General, Appearance, Terminal, Editor, Graphs, Transfers, Network, Updates and Confirmations. Existing application settings appear in their corresponding sections. Tool-specific controls remain available, and changes use the same stored preferences.

## Saved data
Network Toolkit retains preferences, saved profiles, credentials in the credential vault and macros. Updates must preserve all of these and migrate older settings without silently resetting them.

## Updates
Use **Check for updates** for an on-demand check. Stable updates and opt-in beta updates use separate channels. A beta must be explicitly selected. Downloading and installing updates requires user consent and package checksum verification.

Automatic **checks** run at startup and every six hours while enabled. The manual Check for updates remains available, and downloading and installing still require explicit approval.

## Safety
Before installing and restarting, save unsaved documents and review active sessions. Updates must not silently close or discard work.

## Reopen tabs

Use **Ctrl+Shift+T** to reopen a recently closed Text Editor document or an empty Terminal connection tab while that window stays open. This never reconnects a live Terminal session, restores credentials, or writes files automatically. Recently closed entries are kept in memory for this window only and are not persisted.

Removing an ordinary saved diagnostic target displays **Undo** for a short time. Deleting credentials, overwriting files, changing network settings and installing updates still require their existing safeguards.
