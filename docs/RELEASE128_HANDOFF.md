## Scope

Display precedence is manually assigned name, then recognized CLI hostname, then
endpoint-only fallback. A chosen name appears above the smaller endpoint. Stored
connection identity, credential links and addresses must remain unchanged across
saved/recent/open views, rename, reload and detached-session transfers.

Recognition expands beyond127's alphabetic Cisco-like prompts to numeric device
names and documented network/shell prompt structures. User, path and mode/context
must not become the device name. Arbitrarily customized or hostname-free prompts
cannot be universally decoded; ambiguous forms retain a reliable prior name or
fall back to the endpoint. Manual naming remains available for all connections.

This is display metadata only: prompt-paced command readiness and submission,

client configuration or private screenshot/name/address is included in fixtures.
All examples and runtime tests use synthetic data. No universal compatibility or
remote-command acceptance is claimed. Published127 tags/assets are not replaced.
