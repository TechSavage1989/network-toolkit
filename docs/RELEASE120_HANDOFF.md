## Exact delivered scope

### File and folder drag starts

The document-wide Editor tab dragstart capture previously rejected non-tab
sources. A **one-line early return for non-editor-tab sources** now lets file,
folder, selected-text and other ordinary drag events reach their existing handlers.
The rejection/registration/ACK branches for genuine editor tabs are retained.
Reorder, drag-away, explicit moves, ownership and close safeguards are not replaced.
Existing local/SFTP copy validation, remote approval, no-overwrite, path/size/depth
bounds and cancellation remain authoritative. This is event routing, not a new
file/credential capability or a claim that every native drag mode is now supported.

Ordinary internal file-manager drags and prepared outward Windows Explorer copies
remain distinct. Outward copies still use the existing explicit preparation flow;
remote protocol restrictions and staged-copy approval still apply. The full-app
file-row acceptance below uses synthetic API responses, not real files or OLE.
A harmless pre-existing rb-drag-target outline can remain after Escape on editor
pane screenshots; no copy occurs. That cosmetic cancellation state was not fixed.

### Condensed baseline curve and selected-window policy

119 multiplied the detailed curve's time parameters by the entire selected
interval, shrinking recent points as duration grew. 120 separates the displayed
interval from the finite detailed-curve horizon and shares its baseline curve/
inverse across points, ticks, hit testing, pan and anchored zoom. Older real
selected history clusters on the left; no records or source timestamps are invented.

- Long selected windows do not shrink Fit's baseline same-age spacing or change
  the configured recent uncompressed count/curve. The default ten-second recent
  reference remains.
- Mature short windows may **expand** visible spacing to fill both edges. This
  implements the explicit filled-left preference, not an impossible promise that
  arbitrarily short windows retain identical pixel gaps while also filling.
- Initial short history keeps natural startup fill. Five-record/two-second floors,
  exact selected-span labels and original source data remain intact.
- Follow latest preserves Details visibility. Left-only navigator resizing retains
  the right anchor/follow state; right resize or whole-window pan can pause it.
  The 119 elapsed HH:MM:SS and saved clock-format behavior are retained.

Version/release-note rotation, focused regressions and early acceptance artifacts
accompany those changes. All seven workflow jobs remain enabled. No comparison,
Hosts, native Alt-transfer, UAC or unrelated sidebar feature fix is included.
