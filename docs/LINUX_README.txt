NETWORK TOOLKIT FOR LINUX
=========================

This is the portable Linux edition. It runs on 64-bit Ubuntu, Debian, Linux
Mint, Fedora, Arch and other current distributions; nothing is installed.

Start it
--------
1. Extract this folder anywhere you like, for example in your home folder.
2. Open a terminal in the folder and run:  ./network-toolkit
   (or double-click network-toolkit in a file manager that runs programs).

Network Toolkit opens in its own window using Google Chrome, Chromium,
Microsoft Edge, Brave or Vivaldi, whichever is installed. Closing the window
stops the app. Without one of these browsers it opens in your default browser
and stays running until you choose Quit Network Toolkit (the power button at
the bottom of the sidebar). To choose a browser yourself, start it with:
  NETWORK_TOOLKIT_BROWSER=/path/to/browser ./network-toolkit

To add Network Toolkit to your applications menu, open App settings and choose
Add to applications menu.

Where your data is kept
-----------------------
Settings, saved targets and connections are kept in ~/.config/NetworkToolkit
(you can move this folder from App settings).
