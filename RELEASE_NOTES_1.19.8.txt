Network Toolkit 1.19.8 Beta 8

## What's New

- Copied or selected batch output no longer has gaps. Devices that page their output (AOS-CX, Cisco) erase each --More-- prompt with a blank line and a row of spaces before continuing; those leftovers are now dropped, so a copied "show running-config" reads as one continuous listing.

## Additional Details

- Only whitespace-only lines that directly follow a pager prompt are removed. Blank lines elsewhere in device output are kept exactly as received.
- Applies to Last batch and Last command output from pastes, macros and Run commands.
- Saved targets, connection profiles, credential vault, macros, unsaved documents, sessions and settings are kept. Security confirmations and Windows/UAC approval are unchanged.
- This is an opt-in beta. Stable users stay on 1.19.0. Portable executable filename remains Network_Toolkit.exe.
- Validation uses hosted and synthetic fixtures; physical Windows and live-device acceptance is not formally claimed.
