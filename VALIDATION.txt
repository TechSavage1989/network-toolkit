PENDING

LIMITATIONS

revised 1.17.63 passed the original hosted browser workflow.

NETWORK TOOLKIT 1.17.63 VALIDATION

CHANGES
Server-mode Listen on adapter uses the same native select and shared appearance
as the SFTP/FTP client connection-source controls. The listening port remains
on its right. Adapter selection updates the saved server configuration and the
startup request, without an inline menu resizing the settings panel. Server
locking and unavailable saved-address labels are retained.

PASSED LOCALLY
- Root application, internal/desktop and internal/terminal Go suites.
- All 358 JavaScript checks, including three new protocol-specific regressions
  for selection persistence, startup address propagation, control locking,
  duplicate-address filtering and unavailable saved-address preservation.
- Fourteen Python release metadata, publication-guard and packaging tests.
- JavaScript syntax and release metadata/resource validation.

PASSED BUILD AND HOSTED BROWSER CHECKS
- Windows x64 GUI cross-compilation, PE architecture/subsystem and version
  resource checks, using the compile-time embedded icon/resource approach.
- Real Chromium server and client transfer layout regressions in the private
  Checks workflow, at five window sizes in light and dark themes. Coverage
  includes native client/server selector style parity, adapter/port alignment,
  pointer/keyboard selection, unchanged form height while opening choices,
  saved-address reload, sidebar docking and activity resizing/persistence.
- Exact four-member binary-only public update ZIP, CRC integrity, inner file
  checksums, external archive SHA-256 and stable installed executable naming.

LIMITATIONS
Native Windows/WebView2 and real physical network equipment are not available
in this environment. Local Chromium installation failed because the downloaded
browser archive was incomplete; rendered verification is delegated to the
private repository's hosted Checks workflow. No native Windows runtime update
or shortcut migration verification is claimed. The previously reported missing
automatic update banner still has no proven root cause; 1.17.62's reliability
improvements are retained without new updater behavior changes.
