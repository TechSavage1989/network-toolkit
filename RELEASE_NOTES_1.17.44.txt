Network Toolkit 1.17.44 Portable

Changes
- Replaced the duplicated adapter dropdown and repeated adapter label with one full-width, wrapping adapter selector in SFTP, TFTP and FTP server settings. The selected interface name and IP address remain fully visible at narrow window widths.
- SSH File Browser now reuses the authenticated SSH transport from an existing connected Terminal tab. Browse SFTP is available in the Terminal Tools panel and a terminal tab context menu. SSH File Browser also provides a connected-terminal picker.
- File browser operations use separate SSH SFTP subsystem channels while retaining the terminal shell. Closing the browser connection does not terminate the SSH terminal. No additional user credentials are sent when using a terminal session.
- The browser only lists eligible active SSH sessions owned by the main window. Remote file operations verify session ownership and reject mixed credentials, unauthenticated sessions, missing deletion confirmation and stale/disconnected sessions.
- Preserved prior server-start confirmation, resolved-IP diagnostic display, source and network tools.

Requirements and limitations
- Remote SSH servers must support the SFTP subsystem (version 3) as well as SSH shell access.
- Connected SSH sessions in separately detached terminal windows are not offered to the main-window browser.
- Windows x64 native GUI and connections to customer equipment have not been physically validated here.

Tests
- Full Go native test suite passed across all packages; 264 JavaScript regression tests passed.
- Integration fixture verifies one SSH connection serves terminal shell and SFTP list, preview, upload and download without additional SSH TCP sessions, including security checks.
- Chromium interface checks at 630 and 1150 pixel widths verify one adapter picker and a wrapped, contained adapter name. Browser UI model smoke test verifies existing session selection and unlink without credentials.
