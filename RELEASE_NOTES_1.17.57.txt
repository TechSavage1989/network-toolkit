NETWORK TOOLKIT 1.17.57
October 24, 2026

CONSISTENT WORKSPACE LAYOUT

All main tools use Terminal's compact window margins: 10 pixels horizontally
and 8 pixels vertically, reduced to 5 pixels on narrow windows. Content fills
the available window width. Shared panel gaps, heading spacing and topbar
alignment replace tool-specific outer insets. Transfer client and server
workspaces no longer add an extra primary-panel edge inset.
Independent Terminal windows retain their edge-to-edge console layout.

FILE CLIENT SIDEBAR DOCKING

The SFTP, FTP/FTPS and TFTP connection sidebars include Terminal's side-swap
button. Left/right docking is saved separately for each protocol. Pointer
and keyboard resizing follow the selected side, including narrow overlays.
Selecting the active sidebar tab still closes or opens it.

ACTIVE SESSION TOOLS

Terminal's main-window active-session bar includes Open SFTP. It opens the
SFTP tool in Client mode using the selected live SSH session and its existing
authenticated connection. An unrelated previous SFTP folder does not carry
into a newly selected SSH session. Refreshing the same session retains its
current folder.
Independent and detached Terminal windows retain their existing Browse SFTP
sidebar action.

SFTP and FTP/FTPS active-session bars use Terminal's shared styling and
Top/Bottom position preference. They sit beside the file workspace and remain
available when the connection sidebar is closed.

PORTABLE WINDOWS PACKAGE

Run Network_Toolkit_1.17.57_Windows_x64.exe. No installation is required.
Open_Terminal.cmd opens an independent terminal window.
The source folder includes complete editable source and vendored dependencies.
See VALIDATION.txt for completed checks and platform limitations.
