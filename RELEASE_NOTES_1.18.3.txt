Network Toolkit 1.18.3 Beta 3

## What's New

- Find settings more easily with a searchable window and clearly organized sections.
- Reopen supported recently closed tabs with Ctrl+Shift+T.
- Undo an accidental removal of a saved target.

## Additional Details

- Settings are grouped into General, Appearance, Terminal, Editor, Graphs, Transfers, Network, Updates and Confirmations. Existing theme, accent, timestamps, report, storage, vendor and update controls are reused. Specialized tool preferences remain in their own workspaces, reachable from the matching Settings category, without resetting stored values.
- Ctrl+Shift+T safely reopens clean local Editor files by reading their original path and unused Terminal draft tabs. The memory-only history holds at most 10 entries. It never stores passwords, credentials, console output, unsaved Editor text or active session state, and never reconnects to a remote device automatically.
- Reopen is also available from the command search and shortcut guide. Focused Terminal input retains Ctrl+Shift+T for the connected device.
- Removing one saved target offers a 10-second Undo, which restores the original entry and position if the ID is still free. Other deletion reviews and the safeguards around unsaved documents remain unchanged.
- Windows/UAC permissions, Hosts/IP/adapter change review, SSH host-key confirmation, file overwrite checks, and explicit approval and SHA-256 verification for updates are unchanged.
- Portable executable remains Network_Toolkit.exe. This is an opt-in beta, with normal stable updates kept separate.
- Validation uses hosted and synthetic fixtures. Physical Windows and live-device testing have not been performed.
