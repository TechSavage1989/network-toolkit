Network Toolkit 1.21.76

## What's New

- Buttons, tabs, menus and other interface labels no longer become selected when you drag across them. Text fields, editor documents, terminal output and result values remain selectable and copyable.
- Browser right-click menus are suppressed, while Network Toolkit's own menus remain available. Profile names, file permissions and connection-removal questions use the app's dialogs.
- Browser app windows disable extensions, translation prompts and web notifications. The Windows embedded host keeps browser dialogs, password suggestions and developer tools disabled.
- This full release also includes complete multiline command-bar and macro execution, ESXi paced-paste support, and cleaner selected or copied ESXi output from the recent betas.

## Additional Details

- Shared interaction rules apply to the main app, the separate Text Editor and Terminal programs, and detached windows. Normal keyboard editing, terminal selection and explicit Copy actions remain available.
- App text-entry and confirmation dialogs preserve the previous dialog's fields and focus. Cancel, Escape, dismissal or replacement cancels the pending action; connection and item identity are checked again before applying an answer.
- Windows fallback and Linux Chromium-family app windows use the same dedicated-profile launch policy. Browser sandboxing, file dialogs, clipboard access, explicit external links and protections for unsaved work remain enabled.
- An external browser still controls its own window-close confirmation when unsaved work or active sessions need protection. The Linux default-browser fallback also remains subject to that browser's own settings; the Windows embedded host provides the fully app-controlled window.
- Multiline command review offers raw paste or one line at a time, and disabled sends explain their reason. ESXi output cleanup recognizes standard prompts and echoes while preserving ambiguous response text; the output preview explains why direct terminal selection is unavailable.
- Published on the stable channel. Existing connections, credentials, macros, preferences, open work and update-consent requirements are preserved. The Linux edition retains its documented preview limitations.
